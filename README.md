# Ethical Hacking Labs

This repository contains practical ethical hacking coursework conducted in controlled academic lab environments.

## Topics Covered
- Password hashing and password security
- Hashcat
- John the Ripper
- Dictionary, rule-based, mask, hybrid, and brute-force attacks
- Password entropy
- SQL Injection
- Boolean-based SQL Injection
- Time-based SQL Injection
- Vulnerable Flask applications
- Parameterized queries and SQLi remediation

## Disclaimer
All activities were performed in controlled academic environments for educational and authorized security testing purposes only.
